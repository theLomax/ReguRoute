#### Backend API:
**Node.js:** A popular JavaScript runtime for building scalable server-side applications.
**Fastify:** A high-performance, low-overhead web framework for Node.js.
**TypeScript:** For adding static typing to JavaScript, which improves code quality and maintainability.

#### Database:
**PostgreSQL:** A powerful, open-source object-relational database system.
**PostGIS:** An extension for PostgreSQL that adds support for geographic objects, allowing location queries to be run in SQL. This is a very valuable and specialized skill.

#### Routing Engine:
**OpenRouteService (ORS):** A feature-rich, open-source routing engine for calculating routes based on OpenStreetMap data. Showcasing experience integrating with a complex, third-party service like this is a huge plus.

#### Infrastructure & DevOps:
**Docker:** For containerizing individual applications (like your backend). You've built a production-ready, multi-stage Dockerfile.
**Docker Compose:** For orchestrating a multi-container application environment (backend, database, routing engine).

#### Project Structure:
**pnpm Monorepo:** For managing a multi-package project (frontend and backend) within a single repository, which is a common pattern in modern development.

#### Development Tools:
**Git:** The industry-standard distributed version control system for tracking changes and collaborating on code.
